# 🍕 Pizza Sales Dashboard - Excel Project

## 📌 Project Overview

This project is an interactive Pizza Sales Dashboard built in Microsoft Excel. The dashboard helps analyze pizza sales performance by providing insights into revenue, orders, sales trends, and best-selling pizzas.

## 🎯 Objectives

* Analyze overall pizza sales performance
* Track total revenue, total orders, and average order value
* Identify top-selling and low-selling pizzas
* Analyze sales by category and size
* Monitor daily and monthly sales trends
* Create an interactive dashboard using Excel

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning
* Conditional Formatting

## 📊 Dashboard Features

* Total Revenue KPI
* Total Orders KPI
* Average Order Value KPI
* Top 5 Best-Selling Pizzas
* Bottom 5 Selling Pizzas
* Sales by Pizza Category
* Sales by Pizza Size
* Monthly Sales Trend
* Daily Order Analysis
* Interactive Slicers for Filtering

## 📈 Key Insights

* Identified the highest revenue-generating pizzas.
* Analyzed customer ordering patterns.
* Compared sales performance across pizza categories and sizes.
* Visualized monthly and daily sales trends for better business decisions.
